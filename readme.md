# aRacer Pro Unified v2.7

單一 iPhone PWA 分析平台，整合 Dashboard、Vehicle Profiles、Acceleration Lab、Smart WOT、AFR Intelligence、Knock Intelligence、Road Dyno、同步游標、A/B 比較、Performance Score、Toast 與 Report Center。

## 執行

```bash
python3 -m http.server 8080
```

開啟 `http://localhost:8080/aracer_pro_unified_v27/`。正式使用請部署到 HTTPS，再以 iPhone Safari 加入主畫面。

## 注意

Performance Score 與自動摘要是規則式資料指標，不是引擎健康保證。Road Dyno 是道路加速估值，不是馬力機測量。任何燃油與點火調整都應由合格技師依車輛規格、燃料與實車條件判讀。
