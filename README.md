# aRacer Pro 統一分析平台 v2.7

完整繁體中文 iPhone PWA。支援總覽、同步圖表、性能評分、加速分析、全油門、AFR、爆震、道路動力估算、車輛設定及報告匯出。

## 本機執行

```bash
python3 -m http.server 8080
```

正式使用請部署到 HTTPS 靜態網站，再用 iPhone Safari 的「加入主畫面」安裝。


## v2.8 真實 Log 匯入
支援拖放或選擇 .log、.csv、.txt，自動偵測 UTF-8／Big5、逗號／分號／Tab，驗證 Time 與 RPM，顯示解析摘要、取樣間隔與資料預覽。


## v2.9 多檔案比較
支援一次選取或拖放多個 Log。可切換作用中檔案、移除檔案、比較資料筆數、記錄長度、轉速、車速、AFR、WOT、爆震、0–100、60–100、噴嘴率與溫度，並提供轉速疊圖。


## v3.0 AFR 與馬力疊圖
多檔案比較圖表可切換轉速、AFR 與道路估算馬力。AFR 顯示各檔案平均值；馬力疊圖支援輸入總重量並重新計算，結果為道路估算值，非馬力機實測。


## v3.1 圖表設定
設定頁新增自動／固定縮放、RPM、AFR、車速、點火角、溫度範圍，並支援 km/h／mph、hp／PS／kW、N·m／kg-m／lb-ft、°C／°F。比較範圍可選全部、WOT、指定 RPM、車速或時間，設定儲存在瀏覽器本機。


## v3.2 圖表設定即時套用
設定欄位變更後 180 毫秒自動更新一般圖表、多檔案比較與疊圖。可暫停即時套用；設定會同步保存於瀏覽器本機。輸入範圍無效時顯示即時錯誤，不重繪圖表。

## v3.4 PWA 更新中心

- 啟動時檢查 `VERSION.json`
- 發現新版時顯示版本號、建置日期與本次更新內容
- 支援稍後更新與立即更新
- 設定頁可查看完整 `CHANGELOG.json`
- 首次開啟新版時顯示新功能介紹
- GitHub Actions 推送至 `main` 後自動部署 GitHub Pages

在 GitHub Repository 的 Settings → Pages，將 Source 設為 GitHub Actions。


### v3.6 可調參數對照表

新增 AFR、爆震、進氣溫度、水溫、噴嘴使用率與電壓的 ECU 可調參數對照表、五星優先度、關聯感知器、調校優先順序及多檔案基礎 Map 資料組建議。
